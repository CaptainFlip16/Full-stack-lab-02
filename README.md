## 📌 Description
This repository contains the practical deliverables for **Lab 02: Advanced CSS, Flexbox & Bootstrap Utilities**, along with a responsive replication of the **Ventic Admin Dashboard**. ## 🚀 Topics & Technologies Covered

- **HTML5 & CSS3**: Semantic page layout, box model, custom styling, and variable adjustments.
- **CSS Flexbox**: Building responsive 1D layouts using `flex-wrap`, `justify-content`, `align-items`, and `gap`.
- **Positioning & Display**: Controlling element rendering using `position: relative` and `position: absolute`.
- **Pseudo-elements & Pseudo-classes**: Enhancing elements with `::before`, `::after`, `:hover`, and `:nth-child()`.
- **CSS Filters & Effects**: Visual feedback using `grayscale()`, `drop-shadow()`, and smooth `transition` properties.
- **Bootstrap 5 Utilities**: Rebuilding responsive components using Bootstrap flex utilities (`d-flex`, `gap-3`, etc.).

## 💻 Included Projects

### 1. Ventic Admin Dashboard (`/dashboard`)
A full administrative UI dashboard built from scratch featuring:
- Sidebar navigation and top navbar header with search and notification badges.
- Statistical summary cards displaying tickets, revenue in PKR, sales, and weekly percentages.
- Custom styled charts, progress bars, and localized regional metrics for Pakistan.

### 2. Lab 02: Team Showcase (`/lab02-advanced-css`)
A responsive showcase card row solving all required lab tasks:
- **Task 1:** 3-card layout using Flexbox wrapping (`flex-wrap`) and proper spacing (`gap`).
- **Task 2:** Absolutely positioned feature badge relative to its parent card (`position: absolute`).
- **Task 3:** Custom decorative pseudo-elements (`::after` underline on heading and `::before` star icon on badge).
- **Task 4:** Interactive card elevation and smooth `grayscale` to full color transition on avatar hover.
- **Task 5:** Action button alignment using native Bootstrap 5 flex utilities.
- **Task 6:** Alternating card background styling using `:nth-child(odd)` and `:nth-child(even)`.
